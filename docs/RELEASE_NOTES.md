# 北辰 0.8.1-test 更新说明

- 新增距离倍增，可按倍数放大速度、加速度和米制半径，输入框仍保留基础值。
- 「开始运动」会同时开始连续发送；暂停运动后发送继续，报文冻结在当前位置。
- 轨迹页显示当前位置、实际生效参数、发送状态和已发送条数。
- 关闭窗口后台节流，最小化后发送频率不再下降。
- Windows 与麒麟 Linux 首次运行自动创建带应用图标的桌面快捷方式。
- 保持 Electron 22，Windows 包面向 Windows 10/11 x64，Linux 包面向麒麟 V10 ARM64。

## 验证范围

发布工作流执行完整单元测试、生产构建、Windows 原生界面与增量升级／回退冒烟、麒麟 ARM64 离屏启动、包结构与 SHA256 校验。测试包仍须在用户测试机上进行实际验收。
