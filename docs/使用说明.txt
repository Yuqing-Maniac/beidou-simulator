北斗模拟器 0.2.0-test 使用说明

这是测试包。程序按华测 $GPCHC ASCII 报文，通过 UDP 组播收发。

组播地址和端口
默认地址是 224.100.100.1，端口是 6020。这是组播，不是单播。界面上的地址和端口可以改。改完后程序会重新加入组播组。

网卡和 IGMP
顶部「网卡」选择本机 IPv4 地址。程序在该网卡上对组播地址执行加入（IGMP join），并打开 IP_MULTICAST_LOOP，因此本机自己发出的报文也能被本机收到。没有列出网卡时，检查该网卡是否已启用 IPv4。

发送
「发送一次」发出当前报文。
「连续发送」按发送率持续发出。发送过程中按钮文字变成「暂停」，再按一次停止。
默认发送率是 10 Hz。协议表没有规定发送率，10 Hz 是工具建议，可以改。
勾选「使用系统时间」后，每一句的 GPS Week 和 GPS Time 取本机时钟。GPS = UTC + 18 秒，闰秒是工具建议，不是协议原文。取消勾选后仍用数据集或手填的时间。

TCP
TCP 和 UDP 可以各自开关，也可以同时发出同一句。TCP 不是组播。客户端模式连接「对端」和「TCP口」，服务端模式在所选网卡上监听该端口，对方连上后收到同一句。连接状态显示在开关旁边。出站和监听都绑定所选网卡的 IPv4。

轨迹
「轨迹」页是离线格网，不访问外网。可选直线、圆周、8 字，或在地图上点折线。速度单位是米/秒。发出的纬度、经度、航向、东向速度、北向速度和平面速度随轨迹更新。高度和天向速度保持当前值。Gyro Z 只写入航向变化率，角速度单位仍是未规定。经纬度按十进制度写到小数点后 8 位。

本机自检
1. 网卡选本机正在使用的 IPv4，不要留空。
2. 确认地址是 224.100.100.1，端口是 6020。
3. 打开数据集「协议示例原句」。
4. 按「发送一次」。
5. 报文流里应同时出现一条「发送」和一条「接收」。接收行能点开，右侧解析出 Status 61 和 Warning 0102（bit1 车辆轮速中断，bit8 副天线断路）。校验为 *4A。

数据集
界面上有十组测试数据。第一组「协议示例原句」与协议表中的示例逐字节相同，含 *4A 和回车换行。最后一组「故障集」是故意的错校验、缺字段和超范围，不要当成正常输出。其余各组是正常报文。时间、姿态、纬度和经度在「时间、姿态、位置」里，点开后可以改。

协议里没写的内容
角速度单位、差分延时的单位、速度的小数位等，界面和协议页标为「未规定」。发送率、把角速度按 °/s 理解、把 UTC 按 GPS 减 18 秒换算，都标为「工具建议」，不是协议原文。

银河麒麟 V10
带 kylin-v10 的 .deb 和 .tar.gz 面向银河麒麟 V10 桌面版 x86_64（glibc 2.28 一类环境）。不要用更新的 Electron 包替换里面的运行时。
deb：sudo dpkg -i beidou-simulator-0.2.0-test-kylin-v10-x86_64.deb
若提示缺依赖：sudo apt-get install -f
tar.gz：解压后进入 beidou-simulator-0.1.0-test-kylin-v10-x64，运行 ./beidou-simulator。
AppImage：chmod +x beidou-simulator-0.2.0-test-kylin-v10-x86_64.AppImage 后直接运行。若系统没有 FUSE，改用上面的 tar.gz。解压目录名仍带构建时的架构标记 x64，可执行文件是 ./beidou-simulator。

Windows x64
zip：解压后运行 beidou-simulator.exe。
portable：直接运行 beidou-simulator-0.2.0-test-win-x64.exe，不必安装。
Windows 防火墙第一次收组播时，请允许专用网络上的访问，否则收不到报文。

校验
每个安装包旁边的 SHA256SUMS 是文件的 SHA256。上传或拷贝后可以用系统工具核对。
