# 北辰 · 导航模拟器

本地查看华测 `$GPCHC` ASCII 报文。界面按协议表逐项列出字段、范围、线上原文、校验和告警位。默认通过 UDP 组播发到 `224.100.100.1:6020`。

协议表是字段含义的依据。表里没写的单位或范围，界面标成「未规定」。发送率默认 10 Hz，标成「工具建议」。

## 运行

```bash
npm install
npm test
npm start
```

浏览器打开 http://127.0.0.1:43123 。

`npm start` 同时提供页面和组播收发。桌面包装的是同一套页面，组播走 Electron 主进程，不经过这个 HTTP 接口。

测试包版本是 `0.8.1-test`。银河麒麟 V10 x86_64 用 Electron 22（主程序最高依赖 GLIBC_2.17）。UDP 与 TCP 可同时打开。地图使用离线仿真场地底图。

```bash
npm run pack:linux
npm run pack:win
```

新增快速测试／完整配置、启动动画、本机配置与路径存档、JSON 导入导出、JSONL 日志、报文文件回放及简化加速转弯模型。详细说明可在界面点击“使用说明”，或查看 `docs/guide.txt`。

Windows 64 位测试包在 [v0.8.1-test Release](https://github.com/Yuqing-Maniac/beidou-simulator/releases/tag/v0.8.1-test) 下载：便携 ZIP 解压后点击 `BeidouSimulator.exe`；麒麟 V10 ARM64 解压后运行 `BeidouSimulator.sh`。

0.8.1-test：新增距离倍增，可按倍数放大速度、加速度和米制半径，输入框仍是基础值；「开始运动」会同时开始连续发送，轨迹页显示当前位置与发送状态；关闭窗口后台节流，最小化后发送频率不再下降。

0.8.0-test：标准数据集与地图同步运动、六场景快速测试、全局调试时间、参数拖条与精确输入，并更新对应文字和离线语音教程。保留完整 Electron 运行时，优先保证兼容性。

语音教程：顶部“语音教程”可打开 28 章离线中文讲解、逐步定位与结果检查。“使用说明”支持搜索章节和下载约 1.4 万字完整教程。全部音频随软件打包，不依赖系统中文语音包；教程不会自动改参数或发报。教程内容与维护流程见 `docs/tutorial.txt` 和 `docs/TUTORIAL_AUTHORING.txt`。

标准场景连续发送时默认按原始东向/北向速度更新位置，金色轨迹与报文位置共用数据；静止场景保持静止，低速可放大地图查看。快速页以八个通俗场景、开始/停止、只看演示和结果摘要为主。参数拖条与精确输入并存，时间由独立的全局报文时钟统一控制，适用于所有场景和回放网络发送。

0.8.0-test 新增周期启停与正弦蛇形场景；故障注入支持累计比例和可复现随机概率，包含校验、定位丢失、位置跳变、时间滞后与速度异常。只改变发送副本，地图用紫色标记对照故障位置，自动适配正常轨迹与异常点。

内置北京、达茂旗百灵庙镇、湛江、广州四处约 2–3 公里范围的真实 OpenStreetMap 离线矢量摘录。坐标为 WGS84，非整座城市覆盖；来源与 ODbL 许可见 `docs/map-data/README.md`。

从本版开始支持导入 `.bcu` 增量包，按精确基础版本升级应用层并在启动失败时回退。0.7 及以前需要先安装一次本版完整包。后续不变的 Electron、语音与地图不会重复进入增量包。便携版升级快照和已保存偏好独立持久化；升级流程和制作命令见 `docs/UPDATES.md`。
